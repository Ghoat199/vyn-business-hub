# VYN Business Hub v0.1

Next.js-Projekt mit drei Geschäftsbereichen und QR-Code-Generator, der im Browser QR-Codes erzeugt und als PNG herunterlädt.

## Lokal starten

Node.js 20+ installieren, dann `npm install` und `npm run dev` ausführen. Anschließend `http://localhost:3000` öffnen.

## Bereitstellung

GitHub-Repository in einem Next.js-kompatiblen Hostingdienst importieren. Bei Vercel vor gewerblicher Nutzung die Tarifbedingungen prüfen; der kostenlose Hobby-Tarif ist nicht für kommerzielle Nutzung vorgesehen.

## Status

Marketing- und Website-Produkte sind nur Platzhalter. Keine Konten, Zahlungen oder Abos. Vor öffentlichem Geschäftsstart Impressum, Datenschutz und weitere erforderliche Angaben ergänzen.
